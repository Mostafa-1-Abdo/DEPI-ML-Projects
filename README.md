# DEPI Machine Learning Projects Repository

## Overview

This repository serves as a centralized monorepo containing two machine learning projects developed under the Digital Egypt Pioneers Initiative (DEPI). The workspace includes a mini project focused on Human Resources Analytics and a capstone graduation project targeting dynamic last-mile logistics optimization.

---

## Portfolio Projects

| Project Name | Domain | Scope | Primary Objective | Status |
| :--- | :--- | :--- | :--- | :--- |
| **[HRChurn-Employee-Attrition-Intelligence-Predictor](./HRChurn-Employee-Attrition-Intelligence-Predictor)** | HR Analytics | Mini Project | Classification model predicting employee attrition based on workplace parameters | Planning & Setup |
| **[OptiMile-AI-Smart-Last-Mile-Route-Optimization](./OptiMile-AI-Smart-Last-Mile-Route-Optimization)** | Logistics & Supply Chain | Graduation Project | Travel time estimation and dynamic route optimization for last-mile delivery | Planning & Setup |
